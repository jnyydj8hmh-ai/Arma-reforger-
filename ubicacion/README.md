# Ver mi ubicación

Página web que muestra tu ubicación en un mapa, solo si das permiso.
No envía los datos a ningún servidor: todo se queda en tu dispositivo.

## Cómo usarla
1. Descarga `ubicacion.html`.
2. Haz doble clic para abrirlo en tu navegador (Chrome, Edge, Firefox...).
3. Pulsa **Compartir mi ubicación** y acepta el aviso del navegador.

## Nota
Por seguridad, los navegadores solo dan la ubicación en páginas abiertas
localmente (archivo) o por `https`. Si la pones en una web, debe ser con https.
